# Readings

`passages.jsonl` and `sources.json` hold text from 19 English Wikipedia articles, cut into passages by `scripts/build_corpus.py`.

- **Authors:** Wikipedia contributors.
- **Licence:** [Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/). This text, and any copy or adaptation of it, stays under that licence.
- **Changes:** section headings, reference lists and formula markup were removed, and the prose was split into passages of about 150 words. The wording is otherwise unchanged.
- **Versions:** each entry in `sources.json` gives the revision id and a permanent link to the exact version used.

The recorded answers in `../replay/` and the files under `evaluation/` quote these passages and carry the same licence for the quoted text.
